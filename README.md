# 🌍 Theory2Tech

### From GPCET R23 CSE Syllabus to Real-World Technology

Theory2Tech is an AI-powered learning platform that transforms the **R23 CSE syllabus of G. Pullaiah College of Engineering and Technology (GPCET)** into a practical, real-world learning journey.

Instead of treating a syllabus as a list of topics to memorize, Theory2Tech helps students understand:

**What to learn → Why it matters → Where it is used → What they can build → Where to learn more**

---

## 🚀 The Problem

Students often learn computer science concepts from their academic syllabus, but there is a gap between:

- 📚 Academic theory
- 🌍 Real-world technology
- 💻 Practical projects
- 🎥 Quality learning resources
- 🧑‍💻 Existing real-world implementations

A student may know a topic such as **Cloud Computing, Data Structures, Operating Systems, Machine Learning, or Cryptography**, but may not know how that concept connects to actual technologies and projects.

Theory2Tech bridges this gap.

---

## 💡 Our Solution

Theory2Tech converts the GPCET R23 CSE syllabus into an interactive learning experience.

A student selects:

**Subject → Unit → Topic**

The platform then provides:

- 🤖 AI-powered topic explanation
- 🎯 Why the concept is important
- 🔍 Key concepts
- 🧩 Simple examples
- 🌍 Real-world applications
- 💻 Project ideas
- 🔗 Relevant real GitHub repositories
- ▶️ YouTube learning resources through SerpApi
- 📚 Recommended next learning topics

This creates a direct path from **classroom theory to practical technology**.

---

## ✨ Key Features

### 🤖 Gemini AI Learning Assistant

Gemini provides a student-friendly explanation of the selected syllabus topic.

The explanation covers:

- What is the topic?
- Why is it important?
- Key concepts
- Simple examples
- Real-world applications
- What can students build?
- What should students learn next?
- Quick takeaway

The system also provides relevant previous syllabus context so that project directions can consider concepts the student has already learned.

---

### 🔎 SerpApi-Powered YouTube Discovery

Theory2Tech uses **SerpApi specifically for discovering relevant YouTube learning resources**.

For the selected syllabus topic:

```text
Student selects topic
        ↓
Theory2Tech creates a focused search
        ↓
SerpApi searches YouTube
        ↓
Relevant videos are retrieved
        ↓
Top learning resources are displayed
